# Security policy

## Supported versions

Only the latest release gets security fixes. `klausur update` upgrades in place.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/arseeeeN/klausur/security/advisories/new)
with a description, the affected version and, if you can, steps or a `.kl` file that reproduce it.

You'll get an answer within a week. Confirmed issues are fixed in a new release and published
as a GitHub security advisory, crediting you unless you prefer otherwise.
